# 🍎 Smart Carbo

## 📖 Sobre o Projeto

O **Smart Carbo** é um projeto desenvolvido como Trabalho de Conclusão de Curso (TCC) do Curso Técnico em Desenvolvimento de Sistemas.

O objetivo do projeto é desenvolver uma plataforma inteligente para auxiliar pessoas no monitoramento da alimentação, controle de carboidratos e incentivo a hábitos saudáveis por meio da utilização de Inteligência Artificial.

Este repositório contém a primeira versão da interface desenvolvida em **ReactJS**, servindo como base para as próximas etapas do desenvolvimento do sistema.

---

## 🎯 Objetivo

Desenvolver uma solução tecnológica capaz de:

- Monitorar o consumo diário de carboidratos;
- Registrar refeições;
- Exibir gráficos de evolução alimentar;
- Auxiliar na criação de hábitos saudáveis;
- Utilizar Inteligência Artificial para reconhecimento de alimentos por imagem;
- Oferecer recomendações nutricionais personalizadas.

---

## 🚀 Funcionalidades Planejadas

- 📸 Reconhecimento de alimentos por imagem
- 🥗 Diário alimentar
- 📊 Relatórios e gráficos
- 🎯 Metas personalizadas
- 🔔 Lembretes inteligentes
- 🤖 Recomendações utilizando IA
